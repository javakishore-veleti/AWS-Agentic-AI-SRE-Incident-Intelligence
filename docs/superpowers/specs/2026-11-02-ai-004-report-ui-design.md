# AI-004 investigation report screen

The Heddle desk gains `/investigations`, separate from commerce. It asks the investigation agent for a report and shows the timeline, signals, hypotheses, uncertainty, recommendations, and evidence ids. Confidence is labeled not calibrated.

A sample report is labeled as a sample. Export downloads the open report as JSON. The desk does not apply a change.

The agent allows the local desk origin so the browser can read the report.
