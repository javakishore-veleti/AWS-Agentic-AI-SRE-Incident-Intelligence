# AI-007 rubric

`quality` on an investigation report counts deterministic checks. A hypothesis must cite an evidence id that returned items. A candidate cause must cite a deployment row. A symptom must say it is not the cause. An unsupported claim and text that says "ignore previous" fail.

`judge` is `not called`. These checks are not a calibrated score, and no model judged the report. The counterexamples are the tests in `tests/test_rubric.py`.
